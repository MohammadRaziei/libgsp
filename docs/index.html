🛠️ Quick Start

Get started with libGSP in just a few lines of code

python_example.py
import libgsp as gsp

# Create a random graph
G = gsp.graphs.Ring(N=50)

# Generate a smooth signal on the graph
signal = gsp.filters.harmonic(G, k=5)

# Compute Graph Fourier Transform
GFT = gsp.filters.Gft(G)
spectrum = GFT.filter(signal)

# Visualize the result
gsp.plotting.plot_signal(G, signal)
